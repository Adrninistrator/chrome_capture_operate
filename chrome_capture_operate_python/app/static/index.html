前端操作记录事件类型
        

        
抓包开启"记录前端页面操作"时，注入的页面监听并记录以上前端事件；未勾选的类型不装监听、不产生记录。默认不勾选按下/聚焦/滚动——前两者与点击重复、滚动为纯噪音（实测样本中占操作记录约七成）。修改保存后对新注入的页面即时生效，已注入页面在刷新后生效

      

      
Chrome请求类型过滤清单
每行一个类型，如 Stylesheet；常见值：Document(网页加载)/XHR/Fetch/Stylesheet/Script/Image/Font/Media/TextTrack/Manifest/Prefetch/EventSource/Ping/Other。默认仅含静态资源，不要把 Document/XHR/Fetch 加进去（会滤掉网页与接口）；Other 与 EventSource 也不建议加入（Other 含各类杂项请求，EventSource 为 SSE 流式数据，可能承载业务数据如 AI 对话）；修改后即时生效

      
URL后缀过滤清单
每行一个后缀，如 .js；修改后即时生效

      
content-type过滤清单
每行一项，如 image/；修改后即时生效
