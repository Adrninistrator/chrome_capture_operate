## 生成Python脚本具体要求

对于以上条件的搜索结果中标题包含 发票或报销 关键字，且有pdf格式附件的邮件，需要下载pdf附件到本地

- 假如pdf附件只有一个，则直接下载
- 假如pdf附件包含多个，则下载附件中文件名包含 发票或报销的pdf文件，假如文件名包含 行程 则跳过

pdf文件需要下载到桌面的子目录，子目录以当前时间（到毫秒级）为目录名，假如存在同名文件，则新的文件需要在文件名增加序号避免重名

在以上生成的子目录中，需要生成一个html汇总文件，需要人关注的信息需要重点显示，需要包含以下信息

- 标题满足规则，且有pdf附件的邮件及pdf附件信息，各pdf附件是否有下载
- 包含pdf附件但邮件标题不满足要求的邮件
- 邮件标题满足但不包含pdf附件的邮件，需要显示邮件内容中所有非QQ邮箱的链接，供人工打开后下载发票
- 需要显示邮件接收时间（秒级），邮件标题，pdf附件文件名，以上最后两种用于发现其他情况的发票邮件

从最新的邮件开始往旧的处理，处理到第一个满足以上要求，且为已读的邮件时，结束操作（说明后续的邮件都已经处理过了）。若某一页内未找到满足结束条件的邮件，则继续搜索并处理

打开邮件后，显示状态由未读变成已读，需要分析是由打开邮件操作导致的，还是有其他专门请求导致的

脚本使用的会话 sid 必须来自 Cookie 的 xm_sid（不是 .mail.qq.com 的 sid，后者会导致接口返回 ret=-20002 登录态失效），并用 folderlist 响应的 param.sid 校准；接口报错需带上服务端返回的具体原因（stack 字段）便于排查
