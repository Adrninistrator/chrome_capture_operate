# health_check

验证脚本：访问 chrome_capture_operate 的 `/health` 健康检查接口，验证服务运行状态。

## 作用

- 访问 `http://127.0.0.1:{port}/health`（端口优先取本项目 `conf/conf.json` 的 `port`，取不到用默认 33445）
- 服务正常：打印 HTTP 200、服务返回的运行状态与当前时间，退出码 0
- 服务不可达 / 非 200：打印明确错误原因，退出码 1

## 使用说明

- 在"快速执行脚本"页选择本目录下的 `main.py` 点击执行
- 可配合"定时执行脚本"页定时运行，通过执行日志观察服务存活情况
- 无参数；依赖 `requests`（已在本项目虚拟环境中）

## 用途

- 验证"快速执行脚本"页面的执行链路（虚拟环境、stdout 展示、超时控制）
- 验证"定时执行脚本"功能的调度与日志落盘（log/scripts/health_check/{年份}/）
- 作为服务存活探针：服务未启动时给出明确提示
